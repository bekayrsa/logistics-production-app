DEMO_GUIDE.txt

Demo Purpose:
This is a demo of a Production Management web app built with React and Tailwind CSS. It showcases a complete CRUD application with routing, data persistence, responsive design, and dark mode support.

How to Start the App:
1. Ensure Node.js is installed on your system.
2. Run 'npm install' in the project directory to install dependencies.
3. Run 'npm run dev' to start the development server.
4. Open your browser and navigate to the provided URL (usually http://localhost:5173).

Basic Navigation:
- Login Page: Enter your email, select a role (Admin/Operator), and choose or create a company.
- Dashboard: View overview statistics and load demo data.
- Projects: Add, edit, and delete projects.
- Sites: Add, edit, and delete sites.
- Trucks: Add, edit, and delete trucks.
- Capture: Enter daily production data with validation.
- Reports: View all captured data in a table format.
Use the sidebar menu to navigate between different sections of the app.

Where Data is Stored:
All data is stored locally in the browser's LocalStorage. No backend server is required. Data persists between browser sessions but is specific to the current browser and device.

RESET APP
=========

If data breaks or you want to start fresh:
1. Open browser developer tools (F12)
2. Go to Application/Storage > Local Storage
3. Clear all localStorage entries for the app
4. Refresh the app page
